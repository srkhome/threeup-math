# 🎒 小豆豆數學樂園

國小三年級數學的**語音互動學習網站**。純靜態網頁（HTML / CSS / JavaScript），不需要安裝、不需要後端，用瀏覽器打開就能使用，適合手機、平板與電腦。

每一課都有圖解說明、語音朗讀與互動練習，學完還有三份綜合測驗，交卷後會顯示答案、解析與建議複習的課程。

---

## ✨ 功能特色

- 🔊 **語音朗讀**：使用瀏覽器內建的語音合成（Web Speech API），以台灣中文朗讀課文、題目與解析，語速放慢，適合小朋友。
- 🎤 **語音回答**：第一、二課的互動測驗可以用說的回答（需瀏覽器支援，見下方說明）。
- 🖼️ **圖解輔助**：數線、直式算式、尺、點陣、披薩分數等小圖，以內嵌 SVG 繪製，不需另外的圖片檔。
- ✅ **即時回饋**：答題後立刻顯示對錯，並附上解題說明。
- 📝 **綜合測驗**：每份 28 題（是非題 10、單選題 10、計算題 8），滿分 100 分，題目與選項順序每次隨機。
- 📚 **學習足跡**：首頁會在點進過的課程上標示「✅ 學過了」（紀錄只存在使用者自己的瀏覽器）。
- 📱 **行動優先**：手機單欄、平板以上雙欄排版，按鈕與文字都放大，方便手指點選。

## 🚀 使用方式

### 方法一：直接開啟

下載或 clone 專案後，用瀏覽器打開 `index.html` 即可。

```bash
git clone https://github.com/<你的帳號>/<專案名稱>.git
cd <專案名稱>
# 直接用瀏覽器開啟 index.html
```

### 方法二：部署到 GitHub Pages（建議）

1. 把所有檔案推到 GitHub 儲存庫的根目錄。
2. 到儲存庫的 **Settings → Pages**。
3. **Source** 選擇 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`，按 **Save**。
4. 等一兩分鐘後，就能用 `https://<你的帳號>.github.io/<專案名稱>/` 開啟。

部署後是 `https` 網址，**語音辨識（麥克風）功能才能正常使用**。

## 🌐 瀏覽器支援與注意事項

| 功能 | 說明 |
|---|---|
| 語音朗讀 | 建議使用 Chrome、Edge 或 Safari。裝置需有中文（台灣）語音；若不支援，頁面會顯示提示。 |
| 語音回答 | 只有第 1、2 課的測驗有。需要瀏覽器支援語音辨識（Chrome、Edge、部分 Safari），並在 `https` 或 `localhost` 下允許使用麥克風。不支援時仍可用鍵盤輸入作答。 |
| 網路連線 | 樣式與字型使用 CDN（Tailwind CSS、Google Fonts，第 4、5 課另用 Font Awesome），**首次載入需要網路**。 |
| 自動播放 | 瀏覽器規定必須使用者點擊後才能發聲，所以不會一開啟頁面就自動朗讀。 |

## 🛠️ 技術說明

- **純前端**：HTML、CSS、JavaScript，無建置步驟、無框架、無後端。
- **樣式**：[Tailwind CSS](https://tailwindcss.com/)（CDN）。
- **語音**：Web Speech API（`speechSynthesis` 朗讀、`SpeechRecognition` 辨識）。
- **圖示**：內嵌 SVG 與 Emoji；部分課程使用 Font Awesome。
- **資料儲存**：首頁的「學過了」標記使用瀏覽器 `localStorage`，不會上傳任何資料。

## ✏️ 如何修改內容

每個頁面都是獨立的 HTML 檔，題目資料寫在檔案內 `<script>` 的陣列或物件中，可以直接修改。

- **課程頁**：修改 `quizData`／`quizBank`／`cards` 等題庫陣列。
- **綜合測驗**：修改 `const bank = { tf: [...], mcq: [...], calc: [...] }`。
  - `tf`：是非題，`a` 為 `true` 或 `false`。
  - `mcq`：單選題，`opts` 為選項，`a` 為正確選項的文字。
  - `calc`：計算題，`a` 為答案陣列（可有多個輸入格），`units` 為單位。
  - 每題都有 `lesson`（所屬課次）與 `exp`（解析）。
- **新增課程**：複製任一課的檔案，修改內容後，在 `index.html` 新增一張課程卡片並連結到新檔案。
